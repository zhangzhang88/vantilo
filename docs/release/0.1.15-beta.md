## 完整中文发布说明


## 一、本次更新
- 新增 Practice Lab，可输入英文文章并选择原文填词或有序句子组装练习。
- 中文听书和逐句英语朗读整合 Qwen3-TTS，支持在设置中配置独立 TTS API。
- 改进中文朗读的 PCM 流式播放、缓存与音色体验，并优化单词发音。
- 改善 macOS 应用界面与阅读、练习操作，加入项目所有者自制的三个游戏音效。

## 二、详细更新内容
Practice Lab 提供练习内容生成及编辑，英文、中文与音标仍需用户检查。生成的练习不自动写入正式课程。

TTS 可通过应用设置手动配置可信本地或局域网 Qwen3-TTS API 地址、模型和 Key；应用不打包模型权重。中文听书和逐句英语朗读使用统一方案；API 配置和音色调整按应用实际能力提供。
