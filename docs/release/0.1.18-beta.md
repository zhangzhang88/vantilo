## 一、本次更新

- 全面升级为原生 macOS 极简视觉风格，主壳、Agent 工作台、阅读器、发现好书、阅读成长与全局听书栏统一联动 5 套全局主题（浅色、米白、浅绿、蓝色、深色）。
- 设置页「外观与阅读」升级为仿 macOS 系统设置的迷你页面主题预览卡片与紧凑分段排版控件；新增 `⌘1` 对话、`⌘2` 阅读、`⌘3` Practice Lab、`⌘,` 设置、`⌘\` 折叠侧栏快捷键。
- 精修阅读书架、正文与逐句精读、词汇复习卡片、中文听书条、英文打字练习与右侧 AI 助手对话排版；夜间/深蓝模式下正文插图自动柔化护眼。
- 优化全书与整期翻译缓存复用、中文听书预缓冲与响度体验，并修复 Agent 权限模式传递、Runtime 监督与自定义 API 预览相关问题。

## 二、详细更新内容

主窗口标题栏、左侧导航栏、会话侧栏、对话区、发现好书、阅读成长页与底部听书悬浮条现已与 Reader 全局主题实时同步，冷启动自动恢复上次主题；顶栏与阅读顶栏收紧至 44px，账号状态胶囊轻量化，左侧导航移除未上线占位项。书架卡片与封面增加书脊微光与层次阴影；阅读工具栏、查词浮窗、中文听书条与全局听书 Dock 采用毛玻璃质感；设置页「全局主题」改为 16:10 迷你阅读页缩略图网格，并修复三项分段控件折行问题。后端与运行时方面完善中文听书预缓冲与响度处理，增强全书/整期翻译缓存复用与 EPUB 解析兼容，修复权限模式传递与便携 Reader/Runtime 监督边界问题。

## 四、已知限制与风险说明

- 临时签名完整性验证通过（`codesign --verify --deep --strict`），缺少 Developer ID。签名为 `adhoc`，无 Team Identifier。公证未完成，`xcrun stapler validate` 返回 65。本机 Gatekeeper 实测拒绝，`spctl` 返回 3。Intel 真机安装与运行验收为 `NOT RUN`。本版按已有 Beta 分发决策继续发布。[Beta 风险决定](RELEASING.md)
- 开发版真人完整 UI 点击验收未单独记录。本次翻译和语音采用模拟服务，真实翻译质量、语音音质、在线 Codex 响应速度和跨设备升级未单独验证。
- 有道 `dictvoice` 公开分发用途的书面授权尚未获确认，项目所有者知情并接受现有集成风险。

## 五、安装与更新说明

从应用内 Beta 更新通道或 GitHub Release 下载 Universal ZIP。核对 SHA-256，退出 Vantilo，再解压并替换旧版应用。应用内更新会验证下载文件并提示完成手动替换。macOS 可能在首次打开时拦截本 Beta。
