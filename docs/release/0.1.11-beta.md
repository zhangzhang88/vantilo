# Vantilo Beta 0.1.11

Vantilo Beta 0.1.11 is a macOS Universal ZIP containing `arm64` and `x86_64` code slices. The ZIP and SHA-256 sidecar are attached to the GitHub Pre-release. It contains no default magazine seed or EPUB files; import only books and magazines you are authorized to use.

## Highlights

- Improved macOS Dictionary Services entry formatting for inflected words, multi-part-of-speech entries, numbered senses and long definitions.
- Keeps dictionary definitions local to the installed macOS dictionaries; Vantilo does not bundle Apple dictionary databases.
- Preserves English-only source text when the enabled system dictionaries do not provide a Chinese gloss. The local English-only long-entry case was **NOT RUN** because the active system dictionaries on the acceptance Mac did not provide a suitable entry. Synthetic regression coverage is not represented as real-system data validation.

## Third-party service notice — Youdao pronunciation

Vantilo retains Youdao English-word pronunciation using `https://dict.youdao.com/dictvoice`. A word and the selected accent are sent to that third-party service when the user clicks an English word with automatic pronunciation enabled, or presses a manual US/UK pronunciation button. Automatic pronunciation is enabled by default and can be disabled in Reader settings.

Written authorization for this endpoint's use in a publicly distributed desktop application has **not been confirmed**. This is a known third-party service authorization risk; Vantilo does not claim that Youdao has authorized this integration. Availability, terms, throttling and continued operation are controlled by the service. Avoid using it with sensitive words or content.

## Signing and validation limits

- The app is ad-hoc signed and is **not notarized**. macOS Gatekeeper may require the user to review the system's first-open warning. This is not Developer ID or notarization acceptance.
- Universal slices were inspected on an Apple Silicon Mac. Intel hardware installation and feature acceptance: **NOT RUN**; the presence of an `x86_64` slice is not Intel hardware acceptance.
- The packaged app's isolated startup, real macOS Dictionary Services query, and Youdao pronunciation path are exercised on the build Mac as part of local acceptance. A live Youdao playback is reported separately from mocked/intercepted request-path verification; network/service restrictions can prevent live playback.
- Real-account/model inference, real-world magazine/EPUB corpus tests, and live magazine synchronization are **NOT RUN**. Automated Reader tests use synthetic EPUB fixtures and do not establish those behaviors.

See the local build report and source commit for the exact package SHA-256, dependency inventory and test results. The build report is not attached to the public Release.
