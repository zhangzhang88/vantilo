## 四、已知限制与风险说明

- 应用采用 ad-hoc 签名，没有 Developer ID 签名，未经过 Apple 公证；本机 Gatekeeper 检查未通过，macOS 可能阻止首次打开。
- 本次实际运行环境为 Apple Silicon。包含 Intel 架构切片不等于已完成 Intel 真机安装和功能验收；Intel 真机验收未运行。
- 软件更新目前需要用户手动替换应用，不会自动关闭或替换正在运行的应用。SHA-256 用于完整性检查，不是独立的发布者数字签名。
- 软件更新检查在部分网络环境可能失败；此前一次间歇性 `fetch failed` 的具体原因未能确认。更新服务尚未验证自动使用 macOS 系统代理的场景。
- 英语单词发音使用有道 `dictvoice` 接口，并会向该服务发送单词和口音。该接口用于公开分发的书面授权尚未确认；项目所有者已知情并接受现有使用方式的风险，本项目不声称已取得授权。

## 五、安装与更新说明

- 下载 Universal ZIP 并解压。首次安装时，将应用移入所使用的应用程序目录。
- 更新时先退出 Vantilo，再解压新版，将新版应用拖入原应用所在目录并选择替换，重新启动即可；无需先卸载旧版。
- 导入的书籍、阅读进度、词汇和设置保存在用户数据目录，不应因替换应用而删除。建议按自己的需要先备份重要数据。
- 遇到 macOS 阻止打开时，按系统提示检查“隐私与安全性”中的选项；不要关闭系统安全保护。
