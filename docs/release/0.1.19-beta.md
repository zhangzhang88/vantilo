## 一、本次更新

- 全新设计 macOS 立体质感应用图标（焦糖陶土底搭配 V 形翻页书、丝带书签与柔光声波），Dock 与安装包全面换新。
- 退役原 Codex / Agent 工作台与内置 Codex 运行时，应用启动直达阅读主界面，聚焦英文阅读、听书、词汇学习、Practice Lab 与自定义兼容 API，通用安装包体积缩减过半（约 219 MB）。
- 新增电子书单页与双页翻页排版、阅读外观设置抽屉，切换滚动/单页/双页或调整字号行距时精准保持当前段落位置。
- 升级听书体验：新增词句同步高亮、朗读进度同步以及自动跳过页码/日期/版权等干扰内容，支持全书译文导出与本地 TTS 模型安装管理。
- 强化书库与后台任务可靠性：完善书籍删除日志原子恢复、同书中英版并发导入保护、局域网目录模型防误回退与关闭前后台导读写盘排空。

## 二、详细更新内容

本版进一步聚焦 Vantilo 作为 macOS 英文阅读、听书、词汇学习与 Practice Lab 桌面应用的定位。主界面移除原 Codex / Agent 工作台与旧侧栏，启动后直接进入阅读空间，保留顶部「设置」入口与 `⌘1`（阅读）、`⌘2`（Practice Lab）、`⌘,`（设置）快捷键；所有翻译、点词语境释义、在线书籍中文介绍与练习生成均统一使用用户配置的 OpenAI 兼容自定义 API（云端或局域网），并彻底移除了随包的 Codex 二进制运行时。

阅读与听书方面，新增电子书单页/双页分页阅读视图与阅读外观抽屉，布局切换或设置调整后保持原阅读段落不跳丢；听书播放器新增智能跳过页码、日期、版权页等非正文干扰项，支持中文听书与英文朗读的实时词句同步高亮与偏移映射，并提供全书译文导出控件与独立/本机 TTS 模型安装管理。可靠性方面，修复未单独配置目录模型且所选局域网正文模型失效时误回退云端默认模型的问题，完善书库删除回滚、文件名预占、重启日志恢复、目录异常报错保留索引，以及应用关闭前等待后台导读任务写盘完成与按正确顺序关闭服务。图标构建脚本改为直接以 `resources/vantilo-icon.png` 作为规范主图生成 `resources/vantilo.icns`。

从应用内 Beta 更新通道或 GitHub Release 下载 `Vantilo-Beta-0.1.19-universal.zip` 与 `.sha256` 校验文件。核对 SHA-256，退出正在运行的 Vantilo，再解压并替换旧版应用。应用内更新会验证下载文件并提示完成手动替换。macOS 可能在首次打开时拦截本 Beta。
