## 一、本次更新

- 全面优化阅读器与五套全局主题（纸张、复古褐、护眼绿、深海蓝、夜间黑）的视觉一致性：修复有声听书浮层在夜间/深蓝模式下显示为白底的问题，统一 Practice Lab 卡片对比度与主题强调色，移除旧版紫/蓝撞色残留并加入磨砂玻璃、自定义细滚动条与轻量交互动效。
- 升级「阅读成长」与「词汇复习」体验：支持自定义每日阅读目标（15/30/45/60 分钟）、近 7 天趋势柱状图、按月切换日历与四档热力图，以及词汇掌握度分布、复习快捷键盘操作（`Space`/`Enter`、`0–5`、`P`、`S`）、英美双音发音与完成统计。
- 在 macOS 标题栏增加陶土色书本标志徽章，并精简外层窗口标题栏，避免与阅读器主导航栏出现重复入口。
- 移除无法稳定访问且封面展示异常的「发现好书」与 Gutenberg 选书模块，聚焦本地书刊导入、阅读、听书、词汇与 Practice Lab 核心体验。

## 二、详细更新内容

本版在界面精致度、主题适配与核心学习工作流上做了全面梳理与打磨：

1. **五套主题统一与视觉细节打磨**：
   - 修复有声听书浮层（`audiobook-dock`）误用旧主题选择器导致夜间/深蓝模式下底色异常的缺陷，清理紫色硬编码并统一接入当前主题强调色与磨砂玻璃表面，保持 50px 以内的紧凑悬浮高度。
   - 修复 Practice Lab 在深海蓝、复古褐与护眼绿主题下的白底混色发虚问题，使所有卡片与按钮边线随 `--theme-*` 自动适配。
   - 升级书架成长首页卡片（随五套主题同步并展示连续阅读徽章）、首次引导弹窗、阅读器目录/词典浮层、中文阅读标题排版、设置页面输入框聚焦反馈及自定义滚动条，并在 macOS 窗口标题栏加入品牌小徽标，移除冗余视图切换按钮（仍保留 `⌘1`、`⌘2`、`⌘,` 快捷键）。
2. **阅读成长与词汇复习增强**：
   - 阅读成长页面新增每日目标时长切换、7 日阅读时长柱状图、月份翻页控制及 4 档热力图渲染，并与书架首页卡片实时同步。
   - 词汇列表增加掌握度分布条与快捷发音按钮；复习卡片完善揭示后评分交互、完成小结分类统计、美音/英音独立发音以及键盘快捷键支持。
3. **书库体验聚焦**：
   - 完整移除依赖外部不稳定数据源且封面易错乱的「发现好书」/ Gutenberg 页面与后台适配逻辑，缩短主界面与配置链路。

- 本次最终安装包验收聚焦于词汇备份/恢复、并发保护、异常回滚与包结构/版本/图标/架构完整性；开发版已完成本地人工 UI 检查，最终包上未单独执行真实云端/局域网模型翻译质量、真实 TTS 音质与跨设备升级验收。

从应用内 Beta 更新通道或 GitHub Release 下载 `Vantilo-Beta-0.1.20-universal.zip` 与 `Vantilo-Beta-0.1.20-universal.zip.sha256` 校验文件。核对 SHA-256（`0833bc4b8c6b8c5b3c9fb14e06740ac29c25913a494977e3f1168fc078c8e4b2`），退出正在运行的 Vantilo 后解压替换旧版应用。首次打开时如遇 macOS Gatekeeper 拦截，可在访达中按住 Control 点击应用并选择「打开」，或在「系统设置 → 隐私与安全性」中确认处理。
