## 一、本次更新

- 书架新增中英文筛选，改进导入书名识别，合并同一本书的续读和续听入口。
- 电子书和期刊共用底部播放器，切换页面可继续播放。
- 英文书刊可从指定段落开始听中文译文，换段时自动滚动并高亮。
- 播放器可返回当前译文、原文或中英对照，直接复用已缓存的全文译文。

## 二、详细更新内容

中文书朗读原文，英文电子书和期刊朗读中文译文。可在正文或纯译文页点「从本段听」。听完当前期刊文章后停止。底部播放器支持暂停、跳转、倍速、音色、睡眠定时和关闭后续听。「回到中英对照」会恢复当前篇章已展开的全文翻译。

## 三、技术变更与测试结果

- 类型检查、应用与 Reader 生产构建通过。根测试 620 项、独立 CI 测试 6 项、Reader 离线测试 731 项通过，Reader 另有 11 项跳过。隔离 Electron 听书和源码词汇备份回归通过。
- 外置 APFS 构建、Intel 词典辅助程序严格完整性、ZIP 校验、17 个双架构 Mach-O、图标、第三方声明和三个自制音效检查通过。包内 EPUB 数量为零。
- 项目所有者确认了开发版真人验收。最终 ZIP 解包后运行实际应用，用合成书刊和本机模拟翻译、语音服务验证导入、分语种朗读、选段、跨页续播、换段滚动、中英对照恢复、缓存复用和应用完整退出后按原秒数续播。
- 最终安装包通过词汇备份、恢复合并、并发写入、失败回滚、重启恢复、限容 APFS 的真实 `ENOSPC` 以及不可写目录 `EACCES` 验收。限容镜像已卸载并移除。

## 四、已知限制与风险说明

- 签名完整性检查通过。应用采用 ad-hoc 签名，缺少 Developer ID。未公证，包内无公证票据。Gatekeeper 本机实测拒绝，macOS 可能拦截首次打开。
- Intel 真机验收未运行。自动化听书验收使用合成服务，真实翻译质量、语音音质和跨设备升级未单独验证。
- 项目所有者已接受本版的 ad-hoc 签名、未公证、Gatekeeper 拒绝、Intel 真机未验收四项 Beta 分发风险。后续同范围决定见 [发布手册](RELEASING.md)。
- 现有有道 `dictvoice` 公开分发用途的书面授权尚未获确认。项目所有者已知情接受当前集成风险。

## 五、安装与更新说明

从应用的 Beta 更新通道或 GitHub Release 获取 Universal ZIP，核对 SHA-256 后退出 Vantilo，解压并替换旧版应用。应用内更新会校验文件，并提示完成手动替换。
