# Vantilo Beta 0.1.12

Vantilo Beta 0.1.12 is a macOS Universal ZIP with Apple Silicon and Intel code slices. It contains no bundled EPUBs or default magazine library.

## What's new

- Reuses translations between full-text reading and Chinese listening, with model-specific caches.
- Restores sentence reading position across restarts.
- Improves Chinese contextual word meanings and dictionary fallback.
- Shows compact dictionary previews with expandable full entries.

## Verification and limits

- The ZIP integrity and all 17 Mach-O files' arm64 and x86_64 slices were checked. Intel hardware acceptance was **not run**.
- Reader regression tests passed, and the packaged application was launched with an isolated profile. Synthetic Reader tests covered dictionary display, a simulated contextual meaning, sentence position recovery in separate Electron test processes, and no observed automatic TTS playback.
- The owner manually accepted sentence recovery, translation reuse and model switching in the development version. A full packaged-application sentence restart and translation reuse through the packaged production route were **not run**.
- No real external AI was used for the synthetic tests. On a later isolated packaged-app launch, Reader automatically synced one live magazine into the isolated test profile; it was not bundled in the ZIP.

## macOS security

The application has an ad-hoc signature, not a Developer ID signature, and is **not notarized**. Gatekeeper assessment rejected the local candidate and macOS may prevent it from opening. The package uses the default Electron icon. Users should follow macOS prompts; do not disable Gatekeeper globally.

## Third-party pronunciation service

Vantilo uses Youdao's `dictvoice` endpoint for English pronunciation; the selected word and accent are sent to Youdao. Automatic pronunciation can be disabled in Reader settings. Written authorization for this endpoint in a publicly distributed desktop application has **not been confirmed**. The project owner has accepted that risk for this release; this is not a claim of authorization.
