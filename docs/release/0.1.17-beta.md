## 一、本次更新

- 期刊支持一键翻译整期，可暂停并继续，重试时只补译缺失内容。
- 整期翻译完成后，期刊目录显示中文标题。打开文章可直接用已有译文做全文对照和听书。
- 阅读翻译、目录翻译和好书介绍可以选择已保存的自定义 API 模型，译文按模型分别缓存。
- 打开期刊书架时先加载刊期信息，进入单期后再读取文章。修改曾保存密钥的 API 地址时会要求重新填写密钥。

## 二、详细更新内容

整期翻译处理所选模型缺少的标题和段落。目录可使用独立模型生成或重新生成，文章的「全文翻译」和「听中文译文」共用整期任务已保存的结果。可将无需密钥的局域网接口保存为独立服务。切换服务的模型或地址时使用独立的译文缓存。Agent 流式内容即时显示并按批次保存。

## 五、安装与更新说明

从应用内 Beta 更新通道或 GitHub Release 下载 Universal ZIP。核对 SHA-256，退出 Vantilo，再解压并替换旧版应用。应用内更新会验证下载文件并提示完成手动替换。macOS 可能在首次打开时拦截本 Beta。
