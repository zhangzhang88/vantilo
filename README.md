# Vantilo

Vantilo 是一款面向 macOS 的阅读与 AI 助手应用。它把电子书、杂志阅读、翻译、词汇学习和 Codex 工作台放在一个界面中，帮助你阅读英文内容，并使用自定义 API 或 ChatGPT 辅助理解。

> **项目状态：开发测试中。** 当前仓库尚无公开的正式安装版本。通用版测试包已用于实际设备测试；全新电脑上的安装、更新、公证和公开分发仍需验收。下面的说明不代表所有功能已经完成正式发布验收。

## 功能介绍

- **发现好书并阅读**：用中文搜索精选目录、按题材筛选，查看中文介绍与阅读难度；从 Project Gutenberg 获取 EPUB 后加入现有书架。
- **阅读电子书和杂志**：导入 EPUB，在书架中打开文章、章节和目录；支持阅读进度、收藏、笔记等阅读工具。
- **段落与全文翻译**：在阅读器中选择已保存的自定义 OpenAI 兼容 API 或 Codex / ChatGPT。译文按所选引擎和模型分别保存；所选服务不可用时，应用不会悄悄切换到其他模型。
- **自定义模型服务**：保存多个 MiniMax、DeepSeek 或局域网 OpenAI 兼容 API 服务，在阅读设置中切换使用；API 密钥由 macOS 安全存储管理。
- **逐句阅读和点词释义**：逐句查看译文，点击英文单词查看系统词典和由当前阅读模型生成的语境释义；支持设置点击单词时自动发音。
- **中文目录**：可手动选择目录翻译模型并生成目录；导入书籍或检查新刊不会自动翻译整本内容。
- **听书**：在支持的阅读页面播放中文朗读，使用 Ciallo TTS 的“晓辰多语言”音色。朗读文本会发送至该第三方服务，连续播放会预生成后续音频；服务可用性取决于网络和第三方服务状态。阅读中的英文单词发音是独立功能。
- **Codex 工作台**：登录 ChatGPT 后，可以在独立工作台与 Codex 对话、选择可用模型，并在应用的权限边界内处理所选工作区内容。

## 选择 macOS 版本

当前测试包同时支持 Apple Silicon 与 Intel：

| 电脑 | 安装包 | 翻译模型 |
| --- | --- | --- |
| Apple 芯片，如 M1、M2、M3、M4 | Universal macOS 包 | 自定义云端或局域网 API |
| Intel 芯片 | 同一个 Universal macOS 包 | 自定义云端或局域网 API |

在 macOS 菜单栏选择 **苹果菜单 → 关于本机**，即可查看电脑使用的芯片或处理器。

通用包在 Apple Silicon 和 Intel 上使用同一套阅读功能，不包含内置本地 Qwen 模型。两种芯片均可在阅读设置中保存并切换 MiniMax、DeepSeek 或局域网 OpenAI 兼容 API；API 密钥保存在 macOS 安全存储中。

## 安装和首次打开

本地通用测试包会同时支持 Apple Silicon 和 Intel，版本文件与校验值由构建流程生成。只有在 GitHub Releases 页面出现正式版本后，才可视为公开发行版；不要把本机测试包当作正式发行版。

当前候选包使用临时签名，尚未获得 Apple Developer ID 签名或 Apple 公证。将来公开提供测试包时，macOS 可能阻止首次打开，用户需要按系统提示在“隐私与安全性”中确认。正式对外分发前还需要验证干净安装、升级与数据保留。

打开应用后，可以从设置进入阅读设置，添加并测试自定义 API 服务。局域网 API 需要服务端监听可从本机访问的地址，并允许相应网络连接。使用 Codex / ChatGPT 时，在应用中登录 ChatGPT，并在阅读页面选择可用模型。在线服务需要网络、可用账号和相应服务权限。

## 杂志与更新

测试版设计为提供四种杂志的初始期刊，并在应用运行期间定期检查新刊。阅读服务启动后会按状态检查，正常情况下约每三小时检查一次；关闭应用后不会在系统后台持续运行。网络不可用、上游来源变化或访问限制都可能影响检查结果。

应用内的**软件更新检查**与杂志新刊检查是两件事。软件更新检查用于发现 GitHub Releases 上的新稳定版本并打开发布页面；当前不会自动下载安装。预发布版本与正式稳定版本的提示行为可能不同。

项目所有者已确认本人拥有或已取得四种默认杂志随应用分发及获取新刊的权利；目前未提供书面依据，也未经独立核验。发布准备仍需核对第三方资源的使用范围。用户导入的个人电子书和期刊不应被提交到公开仓库。

## 隐私与数据

- 导入的书籍、阅读记录、外观设置、API 服务配置和对话记录保存在本机应用数据目录。数据管理可备份阅读进度、笔记、词汇、阅读偏好和部分翻译缓存；备份不包含 EPUB、API 服务与密钥、中文目录缓存、ChatGPT 登录或 Agent 会话。
- 选择自定义 API 或 Codex / ChatGPT 时，阅读内容会发送到所选服务端点。使用前请核对服务地址、隐私与账号权限。
- 中文听书使用 Ciallo TTS 时，朗读文本会发送到 `tts.ztr8.uk`；请根据内容敏感程度决定是否使用。
- Codex 工作台使用应用独立的登录目录。阅读任务和工作台使用独立执行通道，不共用项目会话；权限、工作区边界及用户批准仍然适用。
- 本地阅读服务绑定回环地址并使用会话验证；这并不等于可以忽略系统安全设置或向不可信程序开放本机数据。

## 开发与测试

项目使用 Electron、React 和 TypeScript。以下命令面向开发者，不能替代安装应用：

```bash
npm install
npm run typecheck
npm test
npm run build
```

阅读器的开发构建依赖单独维护的 Magazine Reader 源码及其已安装依赖；构建适配器默认查找 Vantilo 同级目录中的 `magazine-reader`，也可通过 `VANTILO_MAGAZINE_READER_ROOT` 指定位置。构建时只读取和编译，不修改上游项目。仓库目前不是无需额外源码即可完整构建阅读器的自包含发行工程。

`npm run desktop:dev` 会先构建阅读器再启动开发应用；运行前需要准备上述源码和依赖。普通构建和测试不应包含用户的个人 EPUB、登录资料或模型权重。真实 Codex 推理、真实账号操作和大模型下载不属于默认测试流程。

仓库的 GitHub Actions 运行类型检查和不依赖私有 Reader 源码的核心测试；完整阅读器构建和双架构安装包需要配置本机 Reader 源码、依赖和 Apple Silicon 构建环境。

```bash
npm run desktop:dev
npm run test:reader:host
npm run test:reader:auth
```

本地双架构候选包的构建前提和限制见 [Mac 测试包说明](docs/mac-beta-candidates.md)。阅读器集成边界见 [Reader 集成说明](docs/magazine-reader-integration.md)。

## 当前限制与发布计划

公开发布前仍需完成以下工作：

1. 在 Apple Silicon 与 Intel 真实设备上完成同一通用包的安装、登录、阅读、翻译及更新验收。
2. 在两种设备上验收自定义云端与局域网 API 的点词、翻译、超时及异常恢复。
3. 核对默认杂志及后续新刊的授权范围，检查安装包中所有第三方组件、许可证和来源。
4. 审查发布源码和新增文件，排除私人内容、凭据和模型权重，建立可回滚的 Git 发布基线。
5. 在公开发布页面明确说明系统要求、两个架构的区别、临时签名状态、已知限制和更新方法。
